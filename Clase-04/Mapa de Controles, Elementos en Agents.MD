# Mapa de Controles, Elementos en Agents.MD

| Elemento | Uso real |
| --- | --- |
| **Hooks y `AGENTS.md`** | No se usaron hooks ni se encontraron archivos `AGENTS.md` aplicables. Las reglas vinieron de la guía y del chat. Se trabajó en el clon propio, con datos sintéticos, locators verificados, documentación previa a la ejecución y tests fallidos conservados. |
| **MCP** | Playwright MCP estaba habilitado, pero su navegador no completó la navegación. La suite se ejecutó con Playwright Test Runner, TypeScript y Chromium. |
| **Plugins y herramientas** | Se usó GitHub para leer el repositorio, Plugin Management para buscar una integración de Qase y Computer Use para intentar acceder a su ventana. También se usaron Git, PowerShell, Node/npm y los reportes de Playwright. |
| **Approvals y permisos** | Se usó la sandbox `workspace-write` y un permiso temporal de red para alcanzar la demo. El usuario autorizó las pruebas y la captura de evidencia. La sincronización con Qase quedó pendiente de acceso autenticado. |
